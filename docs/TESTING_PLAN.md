# Milestone 03 Testing Plan

## Functional testing
Cover authentication, event discovery, filters, event CRUD, saves/reminders, verification, reports, alerts and role authorization. Record actual result, evidence and defect ID for every test case.

## Usability testing
Minimum 5 real/proxy participants must test the working app. Record consent, participant role, tasks, completion, time, errors, assistance and satisfaction. Keep session recording links in the report appendix.

Do not reuse prototype-only results as evidence of the working app unless the participant actually tests the implemented application.
