# Backend - NestJS / Node.js

Planned REST API for LankaFest Connect. Dependencies are intentionally not installed.

## Planned modules
- auth
- users
- events
- saved-events
- reminders
- notifications
- reports
- verifications
- alerts

## Database
MongoDB with Mongoose. Configure `MONGODB_URI` in `backend/.env` using `backend/.env.example` as a template. The database connection and Mongoose schemas are still to be implemented.
